# Contributing

Thanks for helping out.

- **Mods** go to [Modz](https://github.com/ModzarellaHQ/modz), not here.
- **Bugs and ideas:** [open an issue](https://github.com/ModzarellaHQ/Modzarella/issues/new/choose). For bugs, say which system you're on and attach `BepInEx/LogOutput.log` if the problem happens in game.
- **Code:** fork, branch, open a pull request. Keep changes focused and match the style around them. [Building](docs/building.md) explains the layout and how to build.

If you change `Modzarella.Core`, rebuild it and commit `src/Modzarella/Runtime/Modzarella.Core.dll` with your change.
